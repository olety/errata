# Errata · the 30-second demo script

The beats follow the submission draft; each beat quotes the draft's line for it. The voice-over is the lead's: the draft fixes only the opening and the closing line. Each beat says what the screen shows when it starts, the exact click, drag or key that moves it on, and what the screen shows after. The game state comes from the synthetic sample, so every figure below is what the recording will show. All of it was checked on the built site at 1440 × 900 (P4 freeze leg, 2026-10-07).

## Setup

- Build and serve the site: `bun run build`, then serve `dist/` (or use https://olety.github.io/errata/). Record at 1440 × 900 in a clean Chromium profile, browser zoom 100 %.
- Use only **Play the synthetic sample**. No folder picker appears anywhere in the clip.
- A drag can always be replaced by two clicks: click the card, then click the target. A key works where it is named.
- Cuts are marked **CUT**. Do the steps under a cut off camera; the clip resumes on the state the next beat names.
- Target length: 30 seconds, at most 35. TTS voice as in Yard #3; subtitles burned in.

## What not to claim in the voice-over

- The game does not test whether an agent follows the lines. Do not say a line prevents anything.
- Token figures are estimates. Say "budget", never "health" or "mana".
- The sample's Apply writes to the browser's private storage, not to real files. The clip shows the sample.
